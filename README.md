# 🎮 فروشگاه اینترنتی گیم سنتر تکاف

### TECCAF Game Center E-commerce Website

فروشگاه اینترنتی گیم سنتر تکاف با تمرکز بر فروش محصولات و خدمات حوزه بازی و کنسول

## 📖 درباره پروژه

این پروژه با هدف طراحی و پیاده‌سازی یک فروشگاه اینترنتی برای **گیم سنتر تکاف** طراحی شده است.

در این وب‌سایت کاربران می‌توانند محصولات و خدمات مرتبط با کنسول‌های بازی، تجهیزات گیمینگ، بازی‌ها و سایر محصولات فروشگاه را مشاهده کرده و محصولات موردنظر خود را به سبد خرید اضافه کنند.

رابط کاربری پروژه به زبان فارسی و با طراحی مناسب برای کاربران ایرانی پیاده‌سازی شده است.

## 🛠️ تکنولوژی‌های استفاده‌شده

- **React** — ساخت رابط کاربری
- **Tailwind CSS** — طراحی و استایل‌دهی
- **React Router DOM** — مدیریت مسیرها و صفحات
- **Vite** — ابزار توسعه و اجرای پروژه
- **JavaScript** — منطق برنامه
- **CSS** — استایل‌های تکمیلی
- **Context API** — مدیریت برخی stateهای سراسری

## 🚀 اجرای پروژه

### 1. نصب وابستگی‌ها

ابتدا در مسیر پروژه دستور زیر را اجرا کنید:

```bash
npm install
```

### 2. اجرای پروژه در حالت توسعه

```bash
npm run dev
```

پس از اجرای موفق، پروژه از طریق آدرس زیر در دسترس خواهد بود:

```text
http://localhost:5173
```
